# Melodist

简单的音乐播放器

- 支持 Android 8.0+ 与 Android TV 8.0+ (API 26+)
  - 标准版：支持 `arm64-v8a` 与 `x86_64`
  - OriginOS：支持 `arm64-v8a`（通过伪装QQ音乐包名以支持 OriginOS 与 ColorOS 媒体控制中心）
  - Android TV：支持 `arm64-v8a`、`armeabi-v7a` 与 `x86_64`
- 没有可靠性支持，软件追求够轻够小，USB独占什么的没能力也没精力去和手机厂商的音频策略搏斗，不提供音乐解析，和官方APP一样需要会员才能正常播放大部分音乐，多设备登录可能导致播放凭证失效（无法播放vip音乐），重新扫码登录就好了，本地不存储播放统计数据，大部分数据都会抛回在线音乐服务器上
- 杜比和DTSX支持需要手机或TV支持对应的解码器才会显示
