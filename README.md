# Melodist

简单的音乐播放器

- 支持 Android 8.0+ 与 Android TV 8.0+ (API 26+)
  - 标准版：支持 `arm64-v8a`
  - OriginOS：支持 `arm64-v8a`（通过伪装包名支持 OriginOS 与 ColorOS 媒体控制中心）
  - Android TV：支持 `arm64-v8a`、`armeabi-v7a`
- 杜比需要手机或TV支持对应的解码器才会显示。DTS仅在TV可用
